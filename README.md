# Faceless YouTube Shorts & Instagram Reels Automation

This repository contains a Python-based FastAPI web service that automatically generates YouTube Shorts and Instagram Reels videos. The service combines a script, voiceover, and background video into a vertical video, suitable for social media platforms.

### Features
- **Fully automated video generation** from a script, audio, and background video.
- **Supports YouTube Shorts** and **Instagram Reels** formats.
- **Easy to deploy and use** with FastAPI and MoviePy.

### Requirements
- Python 3.9 or later.
- Install dependencies by running the following command:
  ```bash
  pip install -r requirements.txt
